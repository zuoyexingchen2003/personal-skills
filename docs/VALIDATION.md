# 验证记录

验证日期：2026-10-24（北京时间）。这里记录实际完成的检查，不把动态适配代码等同于已测试所有朋友的电脑。

## 已实际验证

| 项目 | 实际操作 | 结果 |
|---|---|---|
| 内置 imagegen 补绘 | 从 1440×1920 竖图扩展出横版画面，并按用户要求增加花量 | 完成，检查了完整画面 |
| 照片 AI 放大 | 本机 AMD Radeon(TM) Graphics，官方 ncnn/Vulkan 引擎，`realesrgan-x4plus` | 1672×941 实际变为 6688×3764 |
| 新 Windows 入口 | 同一 64×64 图像局部在 PowerShell 5.1 与 PowerShell 7 分别推理 | 都生成 256×256；两次文件 SHA-256 一致 |
| DPI 下的屏幕探测 | 两个 PowerShell 版本读取原生 API 矩形 | 均为 1920×1200、2560×1440；未把缩放后的 1536×960、2048×1152 当原生像素 |
| 独立屏幕比例 | 16:10 与 16:9 的真实双屏 | 分别生成 3840×2400、5120×2880 PNG |
| 多母图映射 | 一个按显示器 Id 指定的来源，加另一个屏幕的默认来源 | 生成与目标对应的文件和清单 |
| 像素不足拒绝 | 将 64×64 小图用作高分辨率母图 | 在输出或设置桌面前拒绝 |
| 文件改动拒绝 | 给清单加入错误 SHA-256 | 应用前拒绝；原桌面读回未变化 |
| 屏幕配置陈旧拒绝 | 将清单中的原生宽度改为与当前屏幕不一致 | 应用前拒绝 |
| 逐屏应用 | 通过新的通用脚本分别应用两张已核验壁纸 | 两块屏幕实际路径和 Fill 位置读回正确 |
| 设置备份和恢复 | 应用后从保存的备份恢复 | 恢复后的路径与位置读回与原状态一致 |
| 安装器 | 在带空格的隔离目标目录安装三个技能 | 三个 SKILL.md 均存在 |
| 保留已有技能 | 再次执行默认安装 | 原有同名技能未被覆盖 |
| 显式更新备份 | 执行 `-Update` 替换带标记的旧技能 | 新技能正确安装，旧标记仍可从备份找到 |
| 技能格式 | 对三个 SKILL.md 执行 skill-creator 的 quick_validate | 均通过 |
| 完整发布包 | 解压 ZIP，逐文件核对 SHA256SUMS，安装并使用包内默认位置的运行时实际推理 | 发布前执行并核验 |

图像质量检查查看了最终完整图和花瓣、细枝的 100% 局部。高清处理会重建纹理，以上分辨率检查不等同于原照片细节真实性证明。

## 兼容边界

自动识别代码不写死本机屏幕数、设备型号、用户名或分辨率；每次按实时活动显示器生成清单，应用前再次校验。可以为不同方向与比例指定不同母图。

已实测的是上述双屏、GPU 与两个 PowerShell 版本。其他品牌显卡、8K、超宽屏、实体竖屏、多于两块屏幕和远程桌面没有逐一实测；这些场景须在目标机器上先运行 Inspect 并检查生成结果。Windows 10/11 是目标平台，不能把此记录表述成两个 Windows 版本都已做完整硬件实测。

macOS/Linux 自动壁纸控制不在本包已实现或已验证的范围内。内置 image_gen 工具的权限由实际使用环境提供，不由安装包保证。
